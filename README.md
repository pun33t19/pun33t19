## About

I am a backend developer at **Deutsche Bank, Pune**, where I work on trade and banking applications that manage client data, and on the backend infrastructure behind several client-facing banking platforms. I joined in 2024 as a DevOps engineer and moved into backend development in 2025, so I care about how a service is deployed and operated as much as how it is written.

Outside work I build AI-engineering projects aimed at real problems: security for AI-agent tool calls, physics-grounded fault diagnosis, and tools that automate the job search. Before backend work I spent my college years building Android and Flutter apps, mostly at hackathons.

- **Current role:** Backend Developer (Java, Spring Boot), Deutsche Bank
- **Education:** B.E. Computer Engineering, Thadomal Shahani Engineering College (TSEC), Mumbai, 2020–2024
- **Interests:** backend and distributed systems, AI agents and agent security, developer tooling

## Featured Projects

| Project | What it does | Stack |
| :-- | :-- | :-- |
| [**Ledgerline**](https://github.com/pun33t19/ledgerline) | Open-source security layer for AI-agent tool calls. Sits between an agent and its MCP servers, checks every call before it runs, blocks tools whose definitions changed after approval, and records each decision in a tamper-evident ledger. Includes an attack-simulation lab that replays each attack with and without protection. | Python, MCP |
| [**Crux**](https://github.com/pun33t19/crux) | AI investigator for rotating-machine faults. Simulates the vibration each candidate cause would produce, scores the real capture against all of them, and asks for the single measurement that decides. Built with Team MechNova for the Google Cloud AI Builder Cup 2026. My part: the UI, the machine lifecycle logic and its Gemini agent connection. | Python, Gemini, Google Cloud |
| [**LandIt**](https://github.com/pun33t19/LandIt) | AI resume-tailoring platform: resume parsing, ATS scoring, job search ranked by match, bullet rewriting and cover letters, with a human-in-the-loop review of every AI suggestion and content-addressable caching. | Next.js, LangChain |
| [**AutoHunt**](https://github.com/pun33t19/AutoHunt) | Privacy-first automated job search. Parses a resume, matches it against public job boards and company ATS pipelines, scores each role, and emails a curated daily digest. | JavaScript |
